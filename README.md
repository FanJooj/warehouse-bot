# Telegram-бот «Склад»

Бот для учёта товаров на складе, написанный на Python 3.10+ с использованием `aiogram 3` и базы данных `SQLite`.

## Функции
- Добавление товаров (суммирование количества при совпадении названия).
- Списание товаров (выбор из списка, защита от ухода в минус).
- Просмотр актуальных остатков с подсчетом позиций и единиц.
- Поиск товаров по части названия.
- Полное удаление товара с подтверждением.
- История последних 20 операций.
- Ограничение доступа по списку Telegram ID (`.env`).
